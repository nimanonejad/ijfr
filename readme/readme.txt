1. COMPUTING ENVIRONMENT
========================

The replication package was developed and run using MATLAB R2009b with
the Econometrics Toolbox.

The original computations were performed on a standard personal computer.
No GPU or parallel computing is required.

Some of the computational routines may take a substantial amount of time
to run. The actual runtime depends on the computer used for replication.


2. STRUCTURE OF THE REPOSITORY
==============================

The structure of the material is as follows:

- Folder: data
  All datasets used in the study are placed in this folder. The datasets
  are provided in Excel 97-2003 Workbook (.xls) format. Each file
  contains a sheet labelled "information". This sheet provides
  information regarding the origin of the data, access to the data,
  preprocessing, usage restrictions, and the number and name of the
  variable(s) of interest.

- Folder: functions
  All user-written MATLAB functions required by the replication scripts
  are placed here.

- Folder: replication_of_submission
  MATLAB scripts used to produce the tables and figures in the manuscript
  are placed here.

- Folder: replication_of_supplementary_material
  MATLAB scripts used to produce the tables and figures in the
  supplementary material are placed here.

- Folder: plots
  The figures of the manuscript and supplementary material are provided
  here in MATLAB R2009b .fig format as reference versions.

- Folder: results
  Contains the Excel file results.xls with numerical reference results.
  In some cases, numerical results from different models were entered
  into Excel before the corresponding figure was produced.

- Folder: readme
  Contains the readme.txt. file.


3. DATA
=======

All datasets used in the study are publicly available and are included
in the replication package.

The datasets are provided in Excel 97-2003 Workbook (.xls) format.
Each dataset contains an "information" sheet describing the origin,
access information, preprocessing, usage restrictions, and the
variable(s) used in the analysis.

The preprocessing applied to the data consists only of straightforward
transformations required for the analysis, such as taking logarithms.
The relevant preprocessing is implemented in the supplied MATLAB code.

There are no restricted-access, confidential, proprietary, or
NDA-protected datasets used in the study.

No intermediary datasets are created as a separate preprocessing stage.
The supplied MATLAB scripts use the datasets in the "data" folder and
produce the required MATLAB .mat files and numerical results.


4. GENERAL INSTRUCTIONS
=======================

The replication package does not require a separate setup script.

Before running a replication script:

1. Set the current folder to the main folder of the replication package.
2. Open the MATLAB script specified in the instructions for the
   relevant table or figure.
3. Adjust the addpath commands in the script so that they point to the
   relevant folders within the replication package. In particular,
   the scripts may require paths to the "data", "functions",
   "replication_of_submission", or "replication_of_supplementary_material"
   folders, depending on the script being run.
4. Run the script and follow the instructions below.

All user-written MATLAB functions required by the replication scripts
are included in the "functions" folder.

The package was developed using MATLAB R2009b. When using a newer
version of MATLAB, some older MATLAB commands may generate compatibility
warnings or errors. Where relevant, specific compatibility instructions
are provided below.


5. REFERENCE RESULTS AND FIGURES
================================

The file results.xls contains numerical reference results for the
calculations described below. These results allow the numerical output
generated by the replication scripts to be compared with the results
used to produce the figures.

The MATLAB .fig files in the "plots" folder provide reference versions
of the final figures.

For some figures, numerical results are generated by MATLAB and then
entered into Excel before the final figure is produced. In these cases,
the Excel file provides reference numerical results for checking the
replication.

The titles, labels, tick marks, and tick labels of some figures were
adjusted manually after the numerical calculations were completed.
These manual adjustments concern graphical presentation only and do not
affect the underlying numerical results.

FIGURE 1 OF THE MANUSCRIPT (figure1.m)
--------------------------------------

Step 1:
Start MATLAB R2009b, follow the steps in the Section GENERAL INSTRUCTIONS.

Open main.m in the folder "replication_of_submission" and run main.m.
This should provide 18 MATLAB .mat files, each ending with _k for
k = 1,...,18. Each file represents the results for one of the
monitoring variables in Table 1 of the manuscript.

provided below.

Adjust the addpath so that it points to the folder containing the 
MATLAB MAT files generated in Step 1.

Uncomment:
vend=202412;

and comment:
vend=201912;

Then run figure1_computation.m.

The output is an 18x5 matrix called mquant. Columns 1:3 should
correspond to the first three columns in the sheet "figure1" in
results.xls.

Step 3:
Compare the numerical output with the corresponding values in the
"figure1" sheet of results.xls.

Step 4:
Comment:
vend=202412;

and uncomment:
vend=201912;

Run figure1_computation.m again.

The output is an 18x5 matrix called mquant. Columns 1:3 should
correspond to the last three columns in the sheet "figure1" in
results.xls.

Step 5:
Compare the numerical output with the corresponding values in the
"figure1" sheet of results.xls.

Step 6:
Open figure1.m in the folder "replication_of_submission". 
Adjust the addpath so that it points to the folder and ensure 
that figure1.m refers to the supplied results.xls file.

Step 7:
Run figure1.m and compare the resulting figure with figure1.fig in
the "plots" folder.

Step 8:
If necessary, manually match the axis ticks and other graphical
formatting. The resulting figure should be equivalent to the supplied
figure1.fig.

Open main_for.m in the folder "replication_of_supplementary_material".
Set ih=2 in line 14 and run main_for.m. This should provide one
MATLAB .mat file.

Step 2:
Open figure9_supp_computation.m in the folder "replication_of_supplementary_material". 
Adjust the addpath so that it points to the folder containing the 
MATLAB MAT file generated in Step 1. 

Run figure9_supp_computation.m.

The output is a 1x3 matrix called mquant and should correspond to
row 1, columns A, B and C in the "figure9_supp" sheet of results.xls.

Step 3:
Run main_for.m again with ih=3 in line 14.

Step 4:
Run figure9_supp_computation.m again. The output should correspond
to row 2, columns A, B and C.

Step 5:
Repeat the procedure with ih=4 and ih=9. These should correspond to
rows 3 and 4, respectively, in the "figure9_supp" sheet.

Step 6:
Open main_exp.m in the folder "replication_of_supplementary_material". 
Adjust the addpath so that it points to the folder and run main_exp.

Step 7:
Open figure9_supp.m in the folder "replication_of_supplementary_material". 
Adjust the addpath so that it points to the folder containing the 
MATLAB MAT files generated in the previous steps.
 
Run figure9_supp.m and compare the resulting figure with
figure9_supp.fig in the "plots" folder.

Step 8:
If necessary, manually match the axis ticks and transform the lines
to bars.


=======================================================================
GENERAL REPRODUCIBILITY NOTES
=======================================================================

1. All datasets required for the analysis are publicly available and
   are included in the replication package.

2. All user-written MATLAB functions required by the supplied scripts
   are included in the "functions" folder.

3. No restricted-access datasets are used.

4. No intermediary datasets are created as a separate preprocessing
   stage.

5. The Excel file results.xls contains reference numerical results for
   cases where results from computational routines were subsequently
   entered into Excel before generating the final figures.

6. MATLAB .fig files are supplied as reference figures. Some graphical
   elements, including titles, labels, axis ticks and tick labels, were
   adjusted manually in the final presentation.

7. The replication code was developed using MATLAB R2009b with the
   Econometrics Toolbox. MATLAB R2009b is therefore the preferred
   environment for the reproducibility check.

8. The original computations were performed on a standard personal
   computer. No GPU or parallel computing is required.

9. Some computations are computationally intensive. The supplied
   reference results and .fig files are provided to facilitate checking
   of the numerical and graphical results.
